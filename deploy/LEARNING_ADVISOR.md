# 学生学习顾问产品方案（LEARNING ADVISOR）

> 定位：**AI 学习顾问** —— 不是一次性辅导工具，而是基于学生**多维度数据**持续诊断、
> 指导、并向家长给出可读报告与对话式咨询的学习伙伴。
>
> 能力底座：精通之路（自学）+ 错题查缺补漏（诊断补漏）+ 班级层（学校/机构）。
> 三者共同沉淀学生的**数据资产**，顾问消费这些数据提供价值。

## 一、产品定位

| 维度 | 说明 |
|---|---|
| 卖点 | **对学习的持续诊断和指导**，不是"内容"或"工具" |
| 付费方 | 家长（看效果、省心）/ 学校机构（提效、学情）|
| 护城河 | 学生数据越积累越准，迁移成本高；AI 教学闭环（变式讲解/掌握验证）难复制 |
| 差异化 | 市面错题本停在"记录重做"，顾问做到"根源诊断 → 补到会为止 → 持续追踪" |

## 二、三个模式

```
┌─────────────────────────────────────────────┐
│              AI 学习顾问（家长可问、可看）       │
│   定期报告 / 根源诊断 / 下一步建议 / 对话咨询     │
├──────────────┬──────────────┬────────────────┤
│ 模式一         │ 模式二        │ 模式三          │
│ 精通之路       │ 错题查缺补漏   │ 学情顾问报告     │
│（自学）        │（诊断+补漏）   │（家长端）        │
│ 学新知识、掌握、 │ 错题→根源诊断→ │ 多维度数据→     │
│ 间隔复习        │ 变式讲解→掌握验证│ 诊断+建议+讨论  │
└──────────────┴──────────────┴────────────────┘
```

### 模式一：精通之路（已有）
- 知识点图谱（学科包预置）→ 掌握度门控 → 间隔复习
- 自学主线，也是**掌握度数据的来源**

### 模式二：错题查缺补漏（新增）
- 错题自动归集（notebook_entries 已有雏形）
- **根源诊断**：AI 定位错题背后的薄弱知识点（不是"这题错"，是"这知识没理解"）
- **针对性补漏**：AI 讲解 + 变式题（换着考同一薄弱点）+ 掌握验证
- 补漏过程与精通之路打通（薄弱知识点进精通之路补救）

### 模式三：学习顾问报告（新增，家长端）
- 定期生成"学情顾问报告"：学了什么 / 掌握多少 / 哪里弱 / 趋势
- **对话式咨询**：家长问"孩子为什么总是错绝对值？" → AI 基于数据回答根源 + 建议
- 下一步建议：重点补哪个知识点、推荐什么学法

## 三、多维度数据资产（顾问的依据）

| 数据 | 来源 | 用途 |
|---|---|---|
| 知识点掌握度 | 精通之路（mastery）| 诊断薄弱点、进度 |
| 错题与错因 | 错题本（notebook_entries）| 错题分布、补漏 |
| 学习轨迹 | 会话/行为（时长、频率、做题量）| 学习习惯、趋势 |
| 补漏效果 | 变式题/掌握验证 | 评估补漏是否有效 |
| 班级对比（可选）| 班级层 | 横向参照（需谨慎隐私）|

> 数据是护城河的核心：用得越久越准，顾问价值越高，学生/家长迁移成本越高。

## 四、顾问能力（家长端）

1. **定期报告**："本周学了 X，掌握 Y%，薄弱 Z，建议下一步…"
2. **根源诊断**：基于错题 + 掌握度，解释"为什么总错某类题"
3. **针对性建议**：具体到知识点和学法的下一步动作
4. **对话咨询**：家长像问顾问一样与 AI 讨论（自然语言，非固定报表）

## 五、与现有体系的关系

| 现有 | 顾问方案 |
|---|---|
| 精通之路（mastery）| 模式一（已有）|
| 题库/错题本（notebook_entries + /space/questions）| 模式二的数据基础（加诊断+补漏）|
| 学科包（dt_subject_*）| 内容主干（对齐课标）|
| 班级层（school/clase/roles + 身份切换）| 学校/机构场景；家长视角单开 |
| 会话存储 / SSO / 知识库 | 不变 |

## 六、实现路径

1. **阶段一：数据完整** —— 精通之路 + 错题本已有雏形，补齐"错题根源诊断 + 变式补漏"（模式二）
2. **阶段二：顾问报告** —— 聚合多维度数据，生成可读学情报告（模式三的报表部分）
3. **阶段三：对话咨询** —— 家长自然语言问 AI 顾问（模式三的对话部分）
4. **阶段四：班级/学校** —— 班级学情、老师视角（B 端）

## 七、商业模式

| 客户 | 付费点 | 形态 |
|---|---|---|
| 家长（C 端）| 学情顾问报告 / 咨询 / 错题补漏 | 订阅制（月/年）|
| 学校 / 机构（B 端）| 班级学情、AI 作业、私有化定制 | 按学校/班级 |
| 平台（小智）| 能力嵌入 | 分成 / 授权 |

## 八、待确认

- **家长报告频率**：周报 / 月报？是否支持即时咨询？
- **家长是否要有独立入口**（如微信/小程序）还是用 DeepTutor 网页？
- **隐私**：家长只能看自己孩子数据（绑定关系）；班级对比是否开放给家长？
- **变式补漏的题源**：AI 生成 + 学科包题库？
